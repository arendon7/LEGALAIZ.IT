# Evidencia visual M6

Se renderizaron 12 vistas de escritorio y 3 vistas móviles usando el frontend real M6 y respuestas reales obtenidas de la API local. El entorno bloqueó la navegación directa de Chromium hacia localhost; por ello, la composición visual se ejecutó en un documento aislado con el CSS/JavaScript reales y payloads capturados del servidor HTTP real.

Resultado:
- 15 vistas renderizadas.
- 0 errores de consola o ejecución.
- 15 de 15 vistas aprobadas en auditoría estructural de accesibilidad.
- 0 desbordamientos horizontales, identificadores duplicados, controles sin nombre visible, imágenes sin texto alternativo o saltos de jerarquía de encabezados.
- Las cinco hojas de contacto fueron inspeccionadas visualmente.
