# LegalAIZ.it M33.0 — Producción demostrativa integrada

M33.0 porta la activación pública demostrativa aprobada en M31.9 sobre M32.9, conservando la línea jurídica, documental, operativa y de seguridad posterior.

## Activo
- 11 productos, formularios, 11 expedientes sintéticos y 76 documentos demo.
- Generación documental y liberación por hash.
- Revisión jurídica y QA independientes.
- Mesa Jurídica, SLA, notificaciones, comunicaciones sandbox y gobierno de contacto.
- GitHub Pages para la presencia pública estática.
- Docker/Codespaces/Render para la aplicación Python completa.
- Bootstrap automático de la cohorte cuando `LEGAL_PUBLIC_DEMO_MODE=true`.

## Separación obligatoria
`PRODUCTION_AUTHORIZED=true` solo representa producción demostrativa. `REAL_PRODUCTION_AUTHORIZED=false` y `REAL_PAYMENTS_AUTHORIZED=false` permanecen invariantes.
