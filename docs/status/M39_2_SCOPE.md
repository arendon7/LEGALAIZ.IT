# M39.2 — Canonical Release Convergence & Repository Cleanup

## Objetivo
Preparar una base única, limpia y auditable para M40 sin reducir capacidades certificadas.

## Incluye
- documentación canónica;
- política e inventario de limpieza;
- convergencia de ramas/PR;
- eliminación únicamente de candidatos comprobados;
- certificación posterior sobre SHA exacto.

## No incluye
- reescritura de arquitectura;
- cambios funcionales de IA M40;
- eliminación masiva por versión;
- promoción a producción comercial.
