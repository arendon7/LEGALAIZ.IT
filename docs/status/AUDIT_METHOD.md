# Método de auditoría M39.2

La auditoría de limpieza debe comprobar para cada candidato:
1. referencia desde `run.py` o handlers activos;
2. imports Python/JS;
3. carga desde HTML/CSS/JS;
4. referencias en tests y tools;
5. uso en datos, plantillas o generación documental;
6. participación en CI/workflows;
7. compatibilidad/migraciones;
8. trazabilidad/release.

Sólo después puede clasificarse como retirables.
